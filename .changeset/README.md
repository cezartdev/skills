# Changesets

This folder holds changesets generated by developers and agents when modifying or adding skills to `cezartdev/skills`.

## How to add a changeset

Run the following command in the root directory:

```bash
pnpm changeset
```

Follow the prompts to select the bump type (`patch`, `minor`, or `major`) and write a concise summary in English.
The generated markdown file will be tracked by git and automatically processed by the Release workflow upon merging to `main`.
